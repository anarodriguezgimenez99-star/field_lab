# Public repository release

Publish the reviewed `public/preparar-publicacion` branch as the remote `main` branch. Keep local development branches out of the public repository.

Before publishing:

- Use an author email protected by the Git hosting provider for future public commits.
- Keep local environment files, credentials, signing keys and application stores out of Git. The repository `.gitignore` covers common local files.
- Confirm that the preview reference images may be redistributed and include attribution where required.
- Choose and add a license before describing the repository as open source.
- Share a repository link from the post; do not package the entire worktree directory, which contains local Git metadata.
